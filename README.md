# Портфолио Эдгара Мавликеева

Готовый статический сайт-портфолио. Все изображения, анимации, логотипы и шрифты находятся внутри репозитория.

Сайт не требует сборки, установки пакетов или серверной части.

## Состав

- `index.html` — основная страница;
- `styles.css` — стили и адаптивная вёрстка;
- `script.js` — карточки проектов, фильтры, меню и диалоговые окна;
- `assets/` — фотографии, коллажи, анимации, логотипы и шрифты;
- `.nojekyll` — отключает обработку файлов через Jekyll на GitHub Pages.

## Как загрузить на GitHub

1. Создайте новый пустой репозиторий на GitHub.
2. Нажмите **Add file → Upload files**.
3. Перетащите в окно всё содержимое этой папки. Файл `index.html` должен лежать в корне репозитория.
4. Нажмите **Commit changes**.

## Как включить GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save**.

Через несколько минут сайт будет доступен по адресу вида:

`https://имя-пользователя.github.io/имя-репозитория/`

Все пути к файлам относительные, поэтому сайт работает как на основном домене, так и внутри подпапки GitHub Pages.

## Локальный просмотр

Можно открыть `index.html` напрямую или запустить в папке простой локальный сервер:

```bash
python3 -m http.server 4173
```

После этого сайт откроется по адресу `http://localhost:4173`.

## Внешние ссылки

Ссылки на Telegram и резюме в Google Drive остаются внешними и требуют доступа к интернету. Все визуальные материалы сайта хранятся локально в `assets/`.
